# Online Book Store — Final Submission

## Project overview
A responsive front-end demonstration of an Online Book Store with separate client and admin sections.

## Pages included
### Client side
1. Home
2. Categories
3. Book details
4. Cart
5. Checkout

### Admin side
1. Login
2. Dashboard
3. Manage books
4. Manage orders
5. Admin profile

## How to run on a Windows laptop
1. Extract this ZIP file.
2. Open the extracted project folder.
3. Double-click `index.html` to open the client home page.
4. To view the admin demo, open `admin/login.html`.

No server installation is required for this front-end demo.

## Features
- Responsive HTML and CSS layout
- JavaScript sample book catalogue
- Local SVG sample book illustrations
- Browser local-storage cart demonstration
- Admin dashboard and management-page interface
- Original home-page banner artwork

## Important limitation
This is a front-end academic demonstration. It does not include a production database, secure server-side administrator authentication, or real payment processing. Checkout and admin management actions are demo interactions only. Do not enter real payment or sensitive personal information.
